# Самообучающийся харнесс для агента

### Drop-in харнесс, который делает AI-агента доказуемо корректным, измеримым и способным учиться на собственных ошибках.

**Продукт — это харнесс, а не модель.**

`prevent` → `prove` → `measure` → `learn` → `prevent` …

[**English**](README.md) · [**Русский**](README.ru.md) · [Полное руководство](docs/HARNESS.ru.md) · [Философия](docs/PHILOSOPHY.md)

</div>

---

LLM-агент для кодинга — гениальный стажёр с тремя изъянами: забывает всё между
сессиями, непоследовательно следует письменным инструкциям и уверенно заявит,
что работа готова, когда это не так. Длинным промптом это не залатать — правило
в `CLAUDE.md` соблюдается ~80% времени и резко деградирует после ~15 вызовов
инструментов; скиллы срабатывают примерно как подброс монеты.

Поэтому перестаёшь инструктировать и начинаешь **принуждать**. Этот репозиторий —
рабочий харнесс: детерминированные shell-хуки + небольшие скрипты, обёрнутые
вокруг каждого действия агента [Claude Code](https://claude.com/claude-code). Он
превращает мягкий совет в твёрдую физику и умнеет с каждой сессией.

Это **не** агент и не твой продуктовый код. Это обвязка вокруг них. Скопируй
`.claude/` и `scripts/` в любое репо, подгони горстку правил под свой стек — и
оно работает.

## TL;DR — четыре ноги

```
┌─────────────┐   ┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│ 1 ПРЕДОТВРАТ│──▶│  2  ДОКАЖИ   │──▶│  3  ИЗМЕРЬ   │──▶│  4  УЧИСЬ    │
│ блок плохих │   │ «готово» =  │   │ считай все  │   │ майни лог,   │
│ записей на  │   │ компилится  │   │ срабатыв.;  │   │ продвигай    │
│ этапе       │   │ неподделыв. │   │ горячие vs  │   │ паттерны     │
│ записи      │   │ tree-хеш    │   │ мёртвые     │   │              │
└─────────────┘   └─────────────┘   └─────────────┘   └─────────────┘
      ▲                                                        │
      └────────────── петля кормит сама себя ───────────────────┘
```

| | Нога | Одной строкой | Механизм |
|---|---|---|---|
| 1 | **Предотврати** | Блок объективных нарушений до того, как правка ляжет | жёсткие `PreToolUse`-гейты, `exit 2` |
| 2 | **Докажи** | «Готово» не может значить «сломано» | `Stop`-гейт пересчитывает SHA изменённых исходников + typecheck |
| 3 | **Измерь** | Знай, какие правила помогают, а какие вредят | всегда включённые счётчики, инкремент на каждое срабатывание |
| 4 | **Учись** | Каждая сессия стартует умнее | майнер транскрипта + кросс-сессионный реестр продвижения |

Код возврата — это весь контракт: `exit 0` разрешает молча; `exit 2` блокирует и
возвращает причину агенту, чтобы он сам исправился. Это рычаг, превращающий совет
в физику.

```
┌────────────────────────── ОДИН ХОД ──────────────────────────┐
│  промпт пользователя                                          │
│       │                                                       │
│       ▼                                                       │
│  ╔═══════════════════╗   инъекция: правила + ветка + дата      │
│  ║ UserPromptSubmit  ║   + ОДНА самая горячая грабля, на       │
│  ║ prompt-context.sh ║   которую ты наступаешь (направляй)     │
│  ╚═══════════════════╝                                        │
│       │ агент предлагает Write / Edit / Bash                  │
│       ▼                                                       │
│  ╔═══════════════════╗   блок any / ! / расширений / inline   │
│  ║   PreToolUse      ║   схем / запрещ-git / не-того-пм.       │
│  ║ guard-write.sh    ║   КАЖДЫЙ блок инкрементит счётчик.      │
│  ║ guard-bash.sh     ║   (exit 2 = жёсткий отказ)             │
│  ╚═══════════════════╝                                        │
│       │ разрешено                                             │
│       ▼                                                       │
│  ╔═══════════════════╗   format --write, затем lint;          │
│  ║   PostToolUse     ║   arch-gate храповик против baseline    │
│  ║ format/lint/arch  ║   (exit 2 возвращает диагностику);      │
│  ║ track-mcp         ║   отметка использования индекса         │
│  ╚═══════════════════╝                                        │
│       │ агент говорит «готово»                                │
│       ▼                                                       │
│  ╔═══════════════════╗   пересчёт tree-хеша изменённого src;   │
│  ║      Stop         ║   если правки добавили НОВЫЕ ошибки     │
│  ║ check-boundaries  ║   typecheck → БЛОК хода (exit 2).        │
│  ║ → evidence.ts     ║   «готово» обязано компилироваться.     │
│  ╚═══════════════════╝                                        │
└───────────────────────────────────────────────────────────────┘
        │ сессия завершается
        ▼
  ╔═══════════════════╗   retro.ts майнит транскрипт:
  ║   SessionEnd      ║   doom-loops, горячие/мёртвые гейты,
  ║ session-end.sh    ║   пропуски индекса. Пишет карточку
  ║ → retro.ts        ║   памяти, продвигает паттерны 3+ сессий,
  ╚═══════════════════╝   сбрасывает окно счётчиков.
        │
        └──────────────► следующая сессия грузится с уроком
```

## Принципы дизайна (инварианты)

1. **Храповик, а не big-bang.** Гейты амнистируют существующий долг и блокируют
   лишь НОВЫЙ. Репо сходится к целевой архитектуре без переписывания — каждая
   чистка опускает число, которое уже не вырастет обратно.
2. **Данные вне раннера.** Паттерны детекции живут в JSON, а не в скрипте,
   который их ищет, — гейт не матчит собственный исходник.
3. **Fail-open при двусмысленности.** Жёсткий блок только для объективных,
   однозначных правил. Всё, что специфично для стека — advisory: один ложный
   блок убивает доверие оператора.
4. **Предлагай, не правь сам.** Нога обучения никогда молча не переписывает гейт.
   Она предлагает; человек одобряет. Ревью остаётся выше по стеку.
5. **Предохранители везде.** Evidence сам деградирует до advisory после 3
   одинаковых блоков, чтобы агент не застрял; Stop-хуки уважают флаг
   `stop_hook_active`.
6. **Дёшево и локально.** Чистый Bash + Bun. Ни демона, ни сервиса, ни
   API-ключа, ни сети. Каждый хук `<200мс` и fail-open при любой ошибке.

## Быстрый старт

1. **Скопируй** `.claude/hooks/`, `.claude/settings.json` и `scripts/` в своё
   репо (харнесс нацелен на [Claude Code](https://claude.com/claude-code)).
2. **Подгони правила.** `guard-write.sh` несёт универсальные блоки безопасности
   TypeScript (`any`, non-null `!`, `@ts-ignore`, вложенный тернарник, расширения
   в импортах, секреты), применимые везде, плюс пример блока стек-специфичных
   правил, помеченный `# ── customize ──`. Отредактируй их под свои конвенции.
3. **Задай команду typecheck.** Evidence запускает `${HARNESS_TYPECHECK_CMD}`,
   по умолчанию `bun run typecheck` — переопредели в env `settings.json`, если
   используешь `tsc`, `nx`, `turbo` и т.д.
4. **Забазлайнь храповики.** Один раз запусти `bun scripts/arch-gate.ts --update`
   и `bun scripts/evidence.ts --reset`, чтобы амнистировать текущий долг.
5. **Поехали.** Открой сессию. Хуки срабатывают автоматически; `retro.ts` пишет
   первую карточку памяти при завершении сессии.

> Требуется [Bun](https://bun.sh) для `.ts`-скриптов и `bash` + `python3` для
> хуков. Других зависимостей нет, сетевых вызовов нет.

## Эксплуатация

```bash
bun scripts/evidence.ts --status        # текущая отметка evidence
bun scripts/evidence.ts --self-test     # изменённые файлы + tree-хеш, без typecheck
bun scripts/evidence.ts --reset         # пере-базлайн (амнистировать текущий долг)

bun scripts/arch-gate.ts --list         # ворклист архитектурного долга
bun scripts/arch-gate.ts --list=<id>    # нарушения одного правила
bun scripts/arch-gate.ts --update       # зафиксировать снижение долга

bun scripts/retro.ts                    # майнить новейший транскрипт, печать
bun scripts/retro.ts --write            # ещё и записать карточку памяти
bun scripts/retro.ts --reset-counters   # начать свежее окно измерений
```
